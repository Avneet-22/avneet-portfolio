# Personal Portfolio Website

**Name:** Avneet Kaur  
**College:** Farmingdale State College  
**Major:** Computer Programming and Information Systems  

## Project Overview

For this project, I created a personal portfolio website to showcase my education, work experience, technical skills, and college involvement. The purpose of my website is to serve as an online resume where employers, recruiters, and peers can learn more about me and my professional background.

My website includes five main pages: Home, Work Experience, College Involvement, Skills, and Contact. I wanted to create a website that is professional, easy to navigate, and reflects my personality through a simple pink-themed design.

My career goal is to become a data analyst, and this portfolio allows me to highlight my experiences while continuing to develop my web development skills.

## Target Audience

My portfolio website is mainly designed for employers, recruiters, and peers who want to learn more about my professional background. Since my career goal is to become a data analyst, I want potential employers to see my technical skills, internship experience, and college involvement.

I also want my website to be useful for networking and connecting with others in the technology field. By keeping everything organized and easy to navigate, visitors can quickly learn about my experience and qualifications.
## Content Strategy

My portfolio website focuses on highlighting my education, professional experience, technical skills, and college involvement. I wanted to include information that would help employers and recruiters better understand my background and qualifications.

I included my internship and previous work experiences to show the responsibilities I've had and the skills I've developed. I also created a College Involvement page to highlight my leadership roles in Supporting Women in Computing (SWIC), along with events and conferences I've attended.

My Skills page highlights my programming languages, development tools, and professional skills. I also included my resume and LinkedIn so visitors can learn more about my qualifications and connect with me professionally.
## Information Organization

I organized my portfolio website into five main pages to make it easy for visitors to find information.

- **Home:** Introduces who I am, my education, and my career goals.
- **Work Experience:** Highlights my internships and previous jobs, including my responsibilities and the skills I've gained.
- **College Involvement:** Showcases my involvement in Supporting Women in Computing (SWIC), leadership experience, events, and conferences.
- **Skills:** Displays my technical skills, programming languages, development tools, and professional skills.
- **Contact:** Provides ways for employers and peers to connect with me professionally.

I included a navigation bar across the website so visitors can easily move between pages. I wanted each page to focus on a specific part of my background without overwhelming visitors with too much information at once.

## Visual Design

For my portfolio website, I chose a minimalist and professional design with a pink and lavender color scheme. Pink is my favorite color, so I wanted to incorporate it into my website while still keeping everything appropriate for employers and recruiters.

I used a clean layout with organized sections, clear headings, and consistent navigation across all five pages. I wanted visitors to easily find information without the website feeling too crowded.

I also included photos from college events, conferences, and my involvement in Supporting Women in Computing (SWIC). These photos help make my portfolio more personal while showcasing my experiences outside the classroom.

## Interaction and Functionality

I wanted my portfolio website to be interactive while still keeping it simple and easy to use. I included a navigation bar that allows visitors to move between the five main pages.

On my Work Experience page, I used expandable sections so visitors can click to learn more about my previous jobs and internships. I also included interactive photo galleries on my College Involvement page to showcase events, conferences, and other activities I've participated in.

Throughout the website, I included clickable links and buttons to help visitors explore my experience, view my resume, and connect with me professionally.

These features make my website more engaging and allow visitors to find information without having to scroll through everything at once.

## Technical Overview

I created my personal portfolio website using HTML, CSS, and JavaScript. HTML was used to organize the content and structure of each page, while CSS was used to style the website, including the colors, fonts, spacing, and layouts.

JavaScript was used to add interactive features and improve the user experience. I developed my website using IntelliJ IDEA and used GitHub to store and manage my project files.

I also used GitHub Pages to publish my website online so employers, recruiters, and other visitors can access it through a public link.
